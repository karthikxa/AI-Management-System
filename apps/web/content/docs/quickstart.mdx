This page takes you from a fresh terminal to a merged change request (CR).
Every command below is copy-pasteable.

<Steps>

<Step>
### Install the CLI

Run the install script. It downloads the `zed` binary for your OS.

```sh
curl -fsSL https://zed.com/install | bash
```

Zed supports macOS and Linux. There is no Windows binary yet.
</Step>

<Step>
### Sign in

```sh
zed login
```

This opens your browser for sign-in. After you sign in, `zed login` picks
your account and a default [project](/docs/project) for you.
</Step>

<Step>
### Create or clone a project

A new account has no projects yet, so `zed login` has none to pick. Run
`zed init` with a name to create your first project. This scaffolds a
project directory on your machine.

```sh
zed init my-app
cd my-app
zed ship
```

`zed ship` creates the project in Zed Cloud on its first run, then
pushes your code. Run `zed ship` again any time to sync local changes.

To work on a project that already exists in Zed Cloud, clone it instead:

```sh
zed projects clone <project-id>
```

Find `<project-id>` with `zed projects ls`.
</Step>

<Step>
### Run a session

```sh
zed sessions new --prompt "Build the login page"
```

This starts a [session](/docs/work/sessions). The agent works in its own
sandbox, on its own branch, so your project is not touched yet.

Attach to the session to watch progress and reply:

```sh
zed sessions chat
```
</Step>

<Step>
### Review and merge the change request

When the agent finishes, it opens a change request with a summary and
the exact diff.

```sh
zed cr ls
```

This lists the open CRs in your project. Review the one the agent opened, then
merge it to land the work on your default branch:

```sh
zed cr merge 1
```

Replace `1` with the CR number from `zed cr ls`. Nothing reaches your
project's default branch until you merge.
</Step>

</Steps>
